WEBSITE SDN 01 DEMANGAN — V25 BERSIH

Paket ini dirapikan dari versi V24. Semua file website sudah berada langsung di folder utama ZIP, sehingga setelah diekstrak, index.html ada di folder utama.

CARA UNGGAH KE GITHUB PAGES (SETELAH CADANGAN AMAN)
1. Ekstrak ZIP ini di komputer.
2. Buka folder hasil ekstrak yang berisi index.html, style.css, script.js, dan folder assets.
3. Unggah ISI folder tersebut ke repositori GitHub (bukan folder pembungkusnya).
4. Pastikan index.html, style.css, script.js, assets/, admin/, dan folder content/ berada di root repositori.
5. Settings > Pages: Branch main, folder /(root).
6. Tunggu proses Pages selesai, lalu buka alamat Pages.

PENTING: Jangan hapus repositori lama sebelum cadangan ZIP tersimpan dan versi baru berhasil dibuka.
